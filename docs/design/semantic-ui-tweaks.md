# Entry separation, search and Versuś — 9 November 2026

The user requested quiet entry borders and meaningful colour, fewer introductory headings, a more useful desktop search page, glasses on Versuś and a balanced visible reply cadence. Existing themes, logo, public information, source links and authentication scope remain.

Every announcement, registration and event preview now has a thin neutral boundary. Explicit source status supplies the coloured edge and icon: cancellation red, remote teaching blue, duty amber, event teal. Scholarship/support topics use a purple label inferred conservatively from title/excerpt; a source status takes precedence. Colour is accompanied by text/icon. Registration open/upcoming tones use existing timing; urgency still depends on the existing freshness-aware countdown. The cancellation label is deliberately broad ("Odwołane"), since a source can cancel a consultation as well as classes. No source statuses were rewritten or inferred from colour.

The visible overview title "Co słychać na UJ?" and the three catalogue introductions are removed. Screen-reader page headings remain, as do the faculty/date context, filters and exact source-timing metadata. Individual entry boundaries do not add enclosing panels around the assistant or the complete information section.

Search has a larger bordered field, eight concise icon topic buttons and direct links to actual information collections. Its technical full-text-backend fallback banner is removed; the fallback search itself and genuine per-domain errors remain. Desktop results group domains vertically and use two item columns, preventing a large empty column when almost all matches are announcements. Mobile uses one item column. A real read-only search for "stypendium" returned 18 announcements and one toolkit resource; the preview waited for results rather than recording the loading state. Five cancellation entries were also inspected. These counts describe the sampled data, not fixed product claims.

Versuś retains its slim original creature design with newly generated rectangular gold prescription glasses. The generated 4×4 sheet was assembled into shared-palette 96×96 sprites and existing portrait variants. Idle blinking, focused listening, thinking and answering loop while their corresponding activity is mounted; greeting/success/error finish neutral. The answering sequence alternates mouth shapes, gestures, a closed-mouth pose and a blink over 3.6 seconds. Source assets are versioned in the component URL. Static PNGs replace animation under either the system or UJverse reduced-motion setting.

Theme-specific SVG component-transfer palettes preserve the alpha mask and pixel edges. The light theme uses the original navy/gold palette; dark lifts the navy pixels; UJ shifts the body towards a brighter blue. These are static palette transforms, with no animated glow or background surface.

Received text reveals in short word/grapheme-safe groups at 40 ms intervals, with adaptive catch-up. A single ready delta followed by DONE gets a proportional frontend presentation settle of at most 450 ms requested delay, keeping the avatar in answering while the text appears. Browser scheduling can exceed ideal timer deadlines; this is neither inference time nor a measured token rate. Stop, abort, unmount, conversation reset and system/app reduced motion cancel the settle and expose received text immediately. Markdown history stays memoized. No backend SSE delays, model changes, paid model probes or invented tokens-per-second meter were introduced.

Verification follows the user's request to skip automated suites: app compilation/build, code review, real public-data browser previews and intercepted/memory-only chat presentation previews. Desktop/mobile views showed no horizontal overflow at the inspected 1440/390 px widths; the three mascot palettes were inspected. The chat previews demonstrated progressive single-delta reveal, completion, immediate stop and reduced motion without JavaScript page errors. Event-photo previews used the existing trusted transport for the managed browser's certificate limitation, without changing application image URLs or bypassing TLS. No real private account data was exercised.
