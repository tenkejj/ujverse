# Open campus workspace — 9 November 2026

This iteration responds to the user's screenshot and requests for fewer enclosing panels, more photographs, shorter actions and a more visible Versuś. The original logo PNG, mascot artwork, system font and light/dark/UJ colours remain. MCP UI Skills `better-layout` and `better-ui` guided grouping, identifiable controls, image outlines, responsive reading order and reduced motion. React guidance was applied to the changed components; no new library or dependency was introduced.

The homepage uses open sections instead of BaseCard containers around the assistant, information overview and saved items. A 184 px full companion stands beside one labelled question field. The send action sits inside that field, and three short icon buttons send the existing natural questions. Headings and metadata are shorter. The canvas grows to 1,640 px, so large displays spend more space on useful content. A selected information category sits beside a two-photo events preview on wide screens; narrow screens retain the same DOM order. Individual announcements have a small category icon, a headline and a source link, without nested card surfaces or excerpts. Data timing stays visible near each source category.

The event image loss was in the presentation pipeline: `official_events.image_url` was already populated, but the public SELECT and `InfoEvent` normalization discarded it. The image URL now passes through the existing safe-URL normalization. Open `EventPreviewTile` links show real source images, a date and short title; compact variants provide thumbnails in the calendar agenda. The complete event list uses a photo grid. Missing or failed photos use an explicit calendar/date fallback. Saved-item controls and original source links remain. A bounded read-only audit found images for all 14 upcoming events; sampled source URLs returned HTTP 200 JPEG. No scraping job, database write or image generation was needed.

Versuś's small avatars now crop the transparent portrait canvas before display, yielding roughly 41–46 px of visible artwork rather than the former 18–20 px. The circular border is removed. The full chat has a larger welcome companion and identity, short icon actions and a single boundary around the input. An empty chat no longer stretches its input to the bottom of a mostly blank viewport. Streaming, cancellation, composition-safe Enter, user-controlled scroll anchoring and all seven animated/reduced-motion states are retained.

Navigation separates campus links, personal links, an expandable university-services group and fixed utility controls. The original header artwork keeps its aspect ratio. Its desktop portal is aligned to the measured physical viewport centre, including environments where classic scrollbar gutters shift fixed-element origins; the calculation is refreshed on resize and root layout changes rather than applying a guessed visual nudge. Mobile controls remain in their existing accessible layout.

Verification respects the user's request to skip automated suites: production compilation, code review and browser previews only. Actual source photographs were displayed through a preview-only trusted Node transport because managed Chromium rejects the environment's intercepted UJ certificate; the original image bytes and application URLs are unchanged and TLS verification remained enabled. The browser's ordinary failed-image path was also inspected. Preview conversation messages were inserted into browser memory, with no model calls or private account data. There is no usability-study or exhaustive accessibility claim.

The frontend retains its existing large-bundle warning. Vercel's function build also reports the existing, unrelated Supabase relation-type diagnostic in `api/_lib/notificationHelpers.ts`; this UI change does not alter that module or the AI backend.
